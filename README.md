# 🌤️ Multi Weather

**Multi Weather** is a responsive and elegant web application that allows users to search, view, and compare real-time weather information across multiple cities. Built using **React**, **Tailwind CSS**, and **Node.js**, the app delivers a smooth user experience with rich data visualizations.

---

## 🚀 Features

- 🔍 **Search Weather**: Get live weather data for any city across the globe.
- ➕ **Add Multiple Cities**: View weather for several locations at once.
- 📊 **Compare Cities**: Side-by-side comparison of temperature, humidity, wind speed, and more.
- 🌙 **Dark/Light Mode**: Seamless toggle for user preference.
- ⚡ **Fast and Responsive**: Built with Tailwind CSS for a fluid UI on all devices.

---

## 🛠️ Tech Stack

| Frontend       | Backend     | Styling       | API        |
|----------------|-------------|----------------|------------|
